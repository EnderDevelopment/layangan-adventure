# Roblox Layangan Adventure

Layangan Adventure is a Roblox script that allows players to control a layangan (a traditional Indonesian kite) within the game environment. The script includes features for keyboard control, collision handling, and position resetting. It is designed to enhance the gameplay experience by providing an interactive and engaging element.

## Install

1. Download the Layangan Adventure script from the GitHub repository.
2. Open your Roblox Studio project.
3. Create a new model and name it "Layangan".
4. Place the downloaded scripts into the "Scripts" folder within the Layangan model.
5. Ensure the scripts are named correctly:
   - `LayanganKeyboardMovement.server.lua` for keyboard control
   - `LayanganMovement.server.lua` for mouse control
   - `collision_script.lua` for collision handling
   - `reset_script.lua` for position resetting

## Use

1. Open your Roblox game in Roblox Studio.
2. Insert the Layangan model into your game environment.
3. Playtest your game to ensure the Layangan model is functioning correctly.
4. Players can now control the Layangan using the following controls:
   - **W, A, S, D** keys for keyboard movement
   - **Left Mouse Button** to fly the Layangan up
